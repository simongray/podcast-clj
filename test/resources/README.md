Fixtures
========
`feeds/namespace-example.xml` and the `chapters/` and `transcripts/` examples are
copied verbatim from the podcast-namespace repository
(https://github.com/Podcastindex-org/podcast-namespace), which is dedicated to
the public domain under CC0 1.0.

The remaining feeds under `feeds/` are small, hand-written fixtures that each
exercise one real-world quirk. The full corpus of real feeds lives outside git
in `dev-resources/corpus/`; see `dev/corpus.clj`.
